# Every Second, I Miss You · for Julian 💌

A romantic interactive love letter built with React, Vite, Framer Motion, and Tailwind CSS.

Live URL: **[razalpa64.github.io/i-miss-you](https://razalpa64.github.io/i-miss-you/)**

---

## ✨ Features

- **Interactive Envelope & Seal**: Engaging opening animation with sound/visual feedback.
- **Floating Petal & Botanical Effects**: Ambient falling petals and hand-crafted botanical frames.
- **Responsive Layout**: Designed to look stunning on both mobile and desktop screens.
- **Standalone Single-File Build**: Can be packaged into a completely self-contained single `.html` file with embedded assets.

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/razalpa64/i-miss-you.git

# Navigate into the project folder
cd i-miss-you

# Install dependencies
npm install
```

### Local Development

Start the local development server:

```bash
npm run dev
```

### Building for Production

```bash
# Standard production build (outputs to dist/)
npm run build

# Standalone single-file build (outputs to dist-single/index.html)
npm run build:single

# Build both versions
npm run build:all
```

## 📦 Deployment

This repository is configured with GitHub Actions to automatically build and deploy to GitHub Pages on every push to the `main` branch.
